> 순검정 직사각형 · 주제 대부분은 내부 · 특징 하나만 돌파 · 매끄럽고 안정적인 선 · 색 신호 하나

XXD Panel 022는 Codex와 호환 에이전트를 위한 이미지 생성 Skill입니다. 사진에서 정체성, 윤곽, 자세, 동작, 기능과 관계를 고정한 뒤 가로형 또는 세로형 순검정 직사각형 하나를 주 시각 영역으로 만듭니다. 주제 대부분은 그 안에 두고 가장 알아보기 쉬운 구조 하나만 자연스럽게 경계를 넘깁니다.

주제는 간결하고 매끄럽고 안정적이며 자연스러운 손그림 탄성을 지닌 검정 선으로 재구성합니다. 흰 음형이 인식을 맡고 아주 작은 회색면만 구조를 돕습니다. 원본에서 대표 색 하나를 추출해 가장 결정적인 작은 부분 하나만 밝힙니다. 넓은 흰 종이, 비대칭 배치, 국소 크롭과 작은 편집 문자가 돌파 동작을 가볍고 재치 있게 만듭니다.

## 왜 022이 필요한가요

일반적인 ‘검정 면＋선화’는 주제를 직사각형 위에 붙인 포스터 템플릿으로 쉽게 무너집니다. 경계에는 사건이 없고 선은 너무 매끈하며 주제, 검정 영역과 문자가 서로 작동하지 않습니다.

022은 순서를 뒤집습니다.

```text
원본 사실 고정 → 가로형 또는 세로형 순검정 직사각형 하나 선택 → 주제 대부분을 내부에 배치 → 결정적 특징 하나만 경계 밖으로 돌파 → 매끄럽고 안정적이며 탄성 있는 검정 선과 흰 음형으로 재구성 → 원본 색 하나로 작은 한 지점만 밝힘 → 경계, 음형 또는 돌파 방향을 따르는 미세 문자로 마감
```

무관한 사진으로 바꿔도 직사각형 방향, 주제 위치, 돌파 특징, 윤곽, 흰 음형과 문구가 거의 그대로 성립한다면 022가 아닙니다.

## 022의 시각적 원칙

- **순검정 주 영역 하나:** 가로형 또는 세로형 직사각형 하나만 사용하며 여러 장식 블록으로 나누지 않습니다.
- **주제 대부분은 내부:** 최소 세 가지 원본 고유 단서로 정체성, 윤곽, 자세, 동작, 기능과 관계를 보존합니다.
- **돌파 특징은 정확히 하나:** 머리 윤곽, 가지, 지붕, 팔다리 또는 사물 가장자리 중 가장 알아보기 쉬운 구조 하나만 경계에서 나오고, 통과하고, 자라거나 깨뜨립니다.
- **매끄럽고 안정적인 손그림 선:** 검정 선은 간결하고 매끄럽고 안정적이며 자연스러운 탄성을 지닙니다. 눈에 띄는 떨림, 반복 덧그림, 털 같은 노이즈와 기계적으로 균일한 벡터 선은 제외합니다.
- **흰 음형＋미세 회색:** 흰 음형이 인식을 맡고 회색은 아주 작은 면만 차지합니다. 주제를 순검정 실루엣으로 만들지 않습니다.
- **색 신호는 정확히 하나:** 원본에서 대표적인 밝은 색 하나를 추출하고 적당히 정제해 가장 서사적인 작은 부분 하나에만 둡니다. 두 번째 색, 넓은 색면과 전체 착색은 제외합니다.
- **비대칭과 국소 크롭:** 넓은 흰 종이와 치우친 배치로 긴장을 만들고 보조 요소를 복잡한 배경으로 키우지 않습니다.
- **문자도 돌파에 참여:** 짧은 제목 하나와 미세 문자 1–3그룹을 영역 가장자리, 음형, 돌파 방향 또는 윤곽 안에 넣고 별도 라벨처럼 붙이지 않습니다.

## 네 가지 출력, 하나의 검정 영역 돌파 논리

네 가지 모드는 하나만 또는 여러 개를 함께 선택할 수 있습니다. `1`, `1+3`, `1、2、4`, `전체`라고 답하면 Skill이 중복을 제거하고 1→4 순서로 실행합니다. 각 모드는 별도 작업 폴더에 독립적으로 출력되며 한 장의 모음 이미지로 합치지 않습니다. `전체`는 원본 한 장당 PNG 7개(일반 모드 각 1개＋배경화면 4개)를 만듭니다. 크기는 모드별로 표시해 같은 답변에서 지정할 수 있고, 지정하지 않은 일반 모드는 원본에 맞춥니다. 문구는 기본적으로 선택한 모드가 공유하며 모드별 지정도 가능합니다.

| 모드 | 크기 규칙 | 결과물 |
| --- | --- | --- |
| `top-bottom` | 원본 적응형 | 위에는 전체 원본, 아래에는 022 검정 영역 돌파 선화. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `left-right` | 원본 적응형 | 왼쪽에는 전체 원본, 오른쪽에는 022 검정 영역 돌파 선화. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `design-only` | 원본 적응형 | 원본 사진은 보이지 않고 변환 디자인만 표시. 원본 비율과 크기 유지 |
| `wallpaper-pack` | 기기별 네 가지 크기 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치 PNG 개별 출력 |

정확한 사용자 픽셀 > 지정 비율 또는 용도 > 일반 모드의 원본 적응형 순서입니다. 원본 `022.md`의 3:4는 초기 창작 캔버스일 뿐 현재 Skill의 숨은 기본값이 아닙니다.

짝을 이루는 모드의 사진은 절제된 색 보정과 필요한 환경 확장만 적용해 사실성을 지킵니다. 디자인 단독과 배경화면은 사진을 근거로 사용하지만 원본을 보여 주지 않습니다.

### 배경화면 세트: 연결형 또는 독립형

배경화면에는 숨은 기본 크기가 없습니다. 일반 프리셋은 휴대전화 `1440×3200`, iPad `2048×2732`, 데스크톱 `3840×2160`, 스마트워치 `1024×1024`이며 기기별 사용자 지정 크기도 가능합니다.

- **연결형 세트(권장):** 먼저 iPad 기준 작품을 생성하고 승인합니다. 나머지 세 기기는 원본 사진＋동일한 기준 작품을 참조해 각 화면에 맞게 새로 구성합니다.
- **독립형 네 작품:** 각 기기는 원본 사진만 참조하며 영역 방향, 주제 점유율, 돌파 특징, 매끄러운 선 리듬, 색 신호 하나와 문자 관계를 각각 탐색합니다.

연결형은 크롭이 아닙니다. 네 장 모두 따로 생성하고 구성하며 검수하고, iPad→휴대전화→데스크톱→스마트워치 순으로 참조를 이어 붙이지 않습니다.

## 문구는 검정 영역과 돌파 동작의 일부여야 합니다

생성 전에 자동 문구, 사용자 지정 문구, 무문자 출력 중 하나를 선택합니다. 문구가 있으면 대상 언어나 지역도 지정합니다.

자동 문구는 사진에서 보이거나 근거가 있는 감정, 동작, 관계, 시간 또는 작은 이야기에서 짧은 제목을 만듭니다. 따뜻하고 절제되며 고요하고 유머러스하거나 외로울 수 있지만 이 이미지와 긴밀히 묶여야 합니다.

필요할 때 미세 보조문자 1–2개, 근거 있는 짧은 문장, 번호 또는 장 표시를 더합니다. 날짜, 장소, 출처와 번호는 사용자 제공이나 신뢰할 수 있는 근거가 있어야 하며 고급스러워 보이려고 꾸며 내지 않습니다.

사용자가 완성 문구를 주면 그대로 유지합니다. 방향이나 수정 가능한 초안일 때만 대상 독자, 목적, 필수 단어, 어조, 함의를 보존하며 다듬습니다.

언어는 명령문의 언어가 아니라 의도한 독자를 따릅니다.

```text
목표 시장 또는 독자 > 지정한 결과물 언어 > 방향 지시 언어; 모두 불분명하면 생성 전에 질문
```

일본판은 자연스러운 현대 일본어를, 한국 독자용은 자연스러운 현대 한국어와 정확한 띄어쓰기를, 영국판은 영국 영어를 사용합니다. 아랍어판은 기본적으로 자연스러운 현대 표준 아랍어와 올바른 오른쪽에서 왼쪽으로 흐르는 구성을 사용합니다. 외모, 옷, 풍경, 간판으로 국적을 추측하지 않으며 가짜 외국어 문자를 쓰지 않습니다.

## 정확한 기하는 코드가, 작품은 이미지 생성이 맡습니다

이미지 모델이 원본에 묶인 검정 영역, 주제 점유, 정확히 하나의 돌파 특징, 매끄럽고 안정적인 손그림 선, 흰 음형, 미세 회색면, 원본에서 가져온 색 신호 하나와 편집 문자를 만듭니다. `scripts/compose_panel.py`는 캔버스 계획, 정확한 50/50 래스터 합성, 최종 크기와 검수만 수행하며 프로그램 그림으로 결과물을 위조하지 않습니다.

```bash
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --plan --layout left-right --size 2560x1440
python3 scripts/compose_panel.py --audit result.png --layout design-only --size 2048x2048
```

정확한 상하 캔버스는 전체 높이, 좌우 캔버스는 전체 너비가 짝수여야 합니다. 요청 픽셀을 몰래 변경하지 않습니다.

## 경계와 신뢰

- 각 사진은 독립된 작업 안에서만 사용하며 다른 입력, 과거 결과, 예시의 피사체, 색, 문구, 구도를 빌리지 않습니다.
- 호출할 때마다 새 작업 폴더를 만들고 원본과 조건이 같아도 새로 생성합니다.
- 결과물은 PNG 비트맵이며 SVG, HTML, Canvas, 프로그램 드로잉 대체물이 아닙니다.
- 설정된 비트맵 브리지는 정제된 상태만 출력하며 공급자, 엔드포인트, 헤더, 인증 정보, 프롬프트, 응답 본문을 노출하지 않습니다.
- 선택한 일반 모드마다 파일 1개를 반환하고, `wallpaper-pack`을 선택하면 독립 배경화면 4개를 추가합니다. `전체`는 원본 한 장당 PNG 7개를 네 개의 동급 모드 폴더에 저장하며 모음 이미지로 합치지 않습니다.

로컬 합성에는 Python 3와 Pillow가 필요합니다. 안전한 비트맵 브리지는 Python 3.11 이상의 `tomllib`을 사용합니다. 이미지 생성에는 내장 래스터 기능이 있는 호스트 에이전트 또는 이미 설정된 호환 경로가 필요합니다.
